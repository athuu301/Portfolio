# ATHARV IS COOL 🚀 (Neal.fun Style Showcase)

A vibrant, playful `neal.fun`-inspired interactive web app featuring the header **"ATHARV IS COOL"**, 3D card tilt physics, Web Audio SFX, sparkle particles, and quick-preview modals for Atharv's 5 featured web applications.

## Featured Web Applications
1. 🤖 **AI ChatBot**: [https://athuu301.github.io/ChatBot/](https://athuu301.github.io/ChatBot/)
2. 🍍 **Pineapple**: [https://athuu301.github.io/Pineapple/](https://athuu301.github.io/Pineapple/)
3. 🏎️ **Infinite Roads 3D**: [https://athuu301.github.io/Infinite_roads/](https://athuu301.github.io/Infinite_roads/)
4. 🍕 **Food Ordering App**: [https://athuu301.github.io/food-ordering-aap/](https://athuu301.github.io/food-ordering-aap/)
5. 🎒 **Campus Stealth Heist**: [https://athuu301.github.io/Campus-maze-heist/](https://athuu301.github.io/Campus-maze-heist/)

## Features
- **3D Tilt Cards**: Neal.fun style cards that tilt dynamically as your mouse hovers over them.
- **Web Audio Sound Effects**: Retro pop and click blips.
- **Sparkle Particle Explosion**: Click the header or "FLEX" button to trigger interactive fireworks.
- **Quick Live Preview Modal**: Preview any live GitHub Pages project directly inside an iframe overlay.
- **Search & Category Filters**: Filter by Games, AI, Apps, and Fun.
